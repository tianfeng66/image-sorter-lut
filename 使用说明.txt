图片分拣 / LUT 调色工具 · 使用说明
=====================================

这是一个在自己电脑上运行的网页工具，图片不会上传到任何服务器。
功能：文字分拣、色彩分析、构图分析、去边裁剪、LUT 调色。


一、Mac 怎么用
-------------

1. 解压后，双击文件夹里的「启动.command」。

   如果提示「无法打开，因为无法验证开发者」：
   · 在「启动.command」上点右键 → 打开 → 在弹窗里再点「打开」；
   · 如果弹窗里没有「打开」按钮：打开「系统设置 → 隐私与安全性」，
     在页面下方找到这个文件，点「仍要打开」；
   · 以上都不行：打开「终端」，输入 bash 和一个空格，
     把「启动.command」拖进终端窗口，按回车。

2. 第一次打开会自动安装运行环境，需要联网，大约 3~10 分钟，只需要一次。
   电脑上没有 Python 时，会自动打开 Python 官网，下载安装 Python 3.12 后再双击一次即可。

3. 装好后浏览器会自动打开 http://127.0.0.1:8765
   使用期间不要关闭那个黑色的终端窗口，关掉窗口就停止工具。
   以后每次使用，双击「启动.command」即可。


二、Windows 怎么用
-----------------

1. 到 https://www.python.org/downloads/windows/ 安装 Python 3.12，
   安装时勾选「Add python.exe to PATH」。
2. 在解压后的文件夹地址栏输入 cmd 回车，依次执行（第一次需要几分钟）：
     python -m venv .venv
     .venv\Scripts\python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
3. 以后每次启动，在同一个文件夹里执行：
     .venv\Scripts\python app.py
   然后用浏览器打开 http://127.0.0.1:8765


三、怎么填图片文件夹
-------------------

页面左侧「图片文件夹」要填完整路径。
Mac：在访达里选中文件夹，按 Option + Command + C 拷贝路径，再粘贴进去。
Windows：在文件夹地址栏复制路径。


四、各功能说明
-------------

· 文字分拣 / 色彩分析 / 构图分析：点「移出…」会把图片从原文件夹直接挪走（不是复制）。
  建议先用一份图片副本试。
· 去边裁剪 / LUT 调色：导出为新文件，不改动原图。
· LUT 调色：先填 LUT 名称和「参考图文件夹」或「特性描述」，点「生成 LUT」；
  再点「载入待处理图」。拖动滑杆时右侧效果实时变化，停手后显示精确结果。
  想做黑白或单色调，点「预处理」里的「去色」：先把图变黑白，再套各层。
· 去边裁剪导出 JPEG 需要 jpegtran：Mac 上可用 Homebrew 安装（brew install jpeg-turbo）。
· 构图分析需要能看图的大模型：本机安装 Ollama 并下载视觉模型（如 llava），
  或设置环境变量 OPENAI_API_KEY。其他功能不需要。


五、常见问题
-----------

· 安装依赖失败：多半是网络问题，换个网络后重新双击「启动.command」，会自动重装。
· 提示端口被占用（address already in use）：工具可能已经在运行，直接打开 http://127.0.0.1:8765 即可。
